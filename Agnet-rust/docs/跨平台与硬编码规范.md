# 跨平台与硬编码规范

所有新增代码（插件、服务、工具、配置）须遵守本文档规定的硬编码和跨平台规则。代码审查时以此为准。

---

## 1. 硬编码值分类定义

任何**运行时从外部读取的值**（配置、环境变量、常量字段）不得在业务逻辑中直接写死字面量。以下分类说明哪些值可以硬编码、哪些必须通过配置/常量/环境变量间接获取。

| 类别 | 错误示例 | 正确做法 | 违例后果 |
|------|---------|---------|---------|
| **URL/端点** | `"https://api.openai.com/v1"` 写在请求函数中 | 从 `LlmConfig.base_url` 读取，默认值在 `ProviderKind::default_base_url()` 中定义 | 更换 API 提供商/自建代理时必须改代码 |
| **模型名** | `"gpt-4o"` 写在调用处 | 从 `LlmConfig.model` 读取 | 换模型须改代码 |
| **超时秒数** | `.timeout(Duration::from_secs(30))` 写在请求处 | 使用 `DEFAULT_TIMEOUT` 常量或 `config.timeout` | 部署延迟敏感场景不可调 |
| **API 版本号** | `"2023-06-01"` 写死在请求头中 | 定义为 `ANTHROPIC_API_VERSION` 常量，集中管理 | 版本升级须全文搜索替换 |
| **User-Agent** | `"aagnet-llm-thinker/0.2.0"` 嵌入请求构造 | 定义为 `USER_AGENT` 常量 | 修改追踪标识需改多处 |
| **文件路径** | `/etc/config.toml`、`./data/skills`、`C:\Program Files\...` | 通过 `AAGNET_HOME` 环境变量 + `dirs::home_dir()` / `dirs::data_dir()` 解析 | 部署到不同平台或目录结构时路径失效 |
| **数字阈值** | `max_tokens = 4096` 直接设为字段值 | 从 `LlmConfig.max_tokens` 读取，`None` 则不发送该字段 | 模型变更后 token 上限不匹配 |
| **字符串模板** | `"Bearer " + api_key` | **可接受**（`api_key` 来自配置，模板本身不变） | — |
| **平台指令** | `"sh"` / `"-c"` / `"cmd"` / `"/C"` | 通过 `OsKind` 枚举分支选择，`tools/platform.rs:52` 为正确示例 | 在 Windows 上执行 `sh -c` 会报错 |

## 2. 跨平台路径规则

### 2.1 禁止裸用 Unix-only 路径

```
错误：PathBuf::from("/tmp/persist")        ← 仅 Unix
错误：PathBuf::from("/var/log/aagnet.log") ← 仅 Unix
正确：std::env::temp_dir().join("persist")
```

### 2.2 禁止裸用 `~`

```
错误：PathBuf::from("~/.aagnet/data")      ← ~ 不会自动展开
正确：let base = dirs::home_dir().unwrap_or_default().join(".aagnet");
      base.join("data")
```

### 2.3 禁止相对路径依赖 CWD

```
错误：PathBuf::from("resources/skills")      ← 取决于在哪运行 cargo run
正确：通过配置 + 环境变量 + dirs 组合解析
```

### 2.4 路径拼接

```
错误：format!("{}/{}", dir, filename)        ← Windows 上应为 \
正确：dir.join(filename)                     ← PathBuf 自动适配分隔符
```

### 2.5 路径分隔符判断

```
错误：if path_str.contains('/')              ← 忽略 Windows
正确：使用 Path::components() 或 MAIN_SEPARATOR
```

### 2.6 文件扩展名判断

```
错误：name.ends_with(".dll")                 ← Windows-only
正确：列举所有平台可能性（.so / .dll / .dylib），或通过 cfg!() 条件编译
```

### 2.7 临时文件/目录

```
错误：PathBuf::from("/tmp/test_xxx")
正确：std::env::temp_dir().join(&format!("test_{}", uid))
```

### 2.8 数据目录

```
错误：PathBuf::from("~/.aagnet")             ← 不展开且硬编码
正确：dirs::data_dir().unwrap_or_default().join("potoobird")
      并通过 AAGNET_HOME 环境变量支持覆盖（参考 storage.rs）
```

## 3. 测试代码规范

### 3.1 临时路径

- 所有测试必须用 `std::env::temp_dir()` 构造临时路径，禁止硬编码 `/tmp/`、`/nonexistent/`、`./test_data/` 等
- 测试结束后通过 `tempfile` crate 或手动清理（`remove_dir_all`）释放

### 3.2 平台特定测试

需要平台隔离时，使用条件属性：

```rust
#[cfg(target_os = "windows")]
mod windows_tests { ... }

#[cfg(not(target_os = "windows"))]
mod unix_tests { ... }
```

不要在同一个测试函数中用 `cfg!()` 做运行时分支——这会隐藏测试失败。

### 3.3 网络测试

- 依赖外部 API 的测试必须标记 `#[ignore]` 或使用 mock
- 禁止在单元测试中访问 `api.openai.com`、`api.anthropic.com` 等真实端点

## 4. 新增插件/模块自查清单

提交代码前逐条确认：

| # | 检查项 | 通过 |
|---|--------|:----:|
| 1 | 所有 URL 端点来自配置或常量，非字面量写死 | ☐ |
| 2 | 所有模型名称来自配置字段，非硬编码 | ☐ |
| 3 | 所有超时值来自配置或 `DEFAULT_*` 常量 | ☐ |
| 4 | API 版本号定义为模块级 `const`，不散落 | ☐ |
| 5 | User-Agent 定义为 `const USER_AGENT` | ☐ |
| 6 | 文件路径通过 `dirs` + `PathBuf::join()` 构建，无 `/tmp/`、`~`、相对路径 | ☐ |
| 7 | 数字阈值（max_tokens 等）默认 `None` 或从配置读取 | ☐ |
| 8 | 平台特定指令通过 `OsKind` 枚举分支，不假设 `sh` 或 `cmd` | ☐ |
| 9 | 测试中无 Unix-only 路径，均用 `std::env::temp_dir()` | ☐ |
| 10 | `cargo build` + `cargo test` + `cargo clippy` 全部通过 | ☐ |

---

## 5. 生效范围

- 本文档适用于所有 `plugins/`（插件）、`core/`（核心）、`infra/`（基础设施）目录下的 Rust 源码
- 配置文件和构建脚本（`*.toml`、`*.ps1`、`*.sh`）参照执行，不强制
- 已有代码不在本文档约束范围内（新提交新修复）
