## 2. 推荐执行顺序

### 2.1 顺序执行（最安全，3 个工作日）

```
Day 1 上午：Skills Plan Phase A-B（10 个任务）
   ↓ 验证（见 §3.1）
Day 1 下午：Skills Plan Phase C-D（12 个任务）
   ↓ 验证（见 §3.1）
Day 2 上午：L3 Plan Phase A（5 个任务，feature flag 基础设施）
   ↓ 验证（见 §3.1）
Day 2 下午：L3 Plan Phase B（6 个任务）
   ↓ 验证（见 §3.1）
Day 3 上午：L3 Plan Phase C-D（8 个任务）
   ↓ 验证（见 §3.1）
Day 3 下午：MCP Plan Phase A-B（13 个任务）
   ↓ 验证（见 §3.1）
Day 4 上午：MCP Plan Phase C-D（7 个任务）
   ↓ 验证（见 §3.1）
Day 4 下午：跨任务回归 + 文档同步
   ↓ 验证（见 §3.2）
```

### 2.2 并行执行（更快，但需要协调）

**前提**：必须有 2 个或以上 AI Agent 同时工作（或一个 AI 多线程）

```
并行 1：Skills Plan 全部（22 个任务） + L3 Plan Phase A 全部（5 个任务）
   ↓ 协调点：共享 `src/shared_types/mod.rs`
   ↓ 解决：先做 Skills Phase A-2，再做 L3 Phase A-4
并行 2：MCP Plan Phase A 全部（5 个任务）
并行 3：L3 Plan Phase B-D 全部（14 个任务）
   ↓ 协调点：MCP 启动顺序 vs L3 启动顺序（互相不依赖）
   ↓ 验证（见 §3.1）
跨任务回归：cargo check / cargo test / 4 协议 grep
```

### 2.3 我的推荐

**顺序执行**。理由：
- 1 个人 + 1 个 AI 的场景，并行没收益（AI 也只能顺序跑 prompt）
- 串行的中间验证更早暴露问题
- 3 个工作日专注可以做完
- 文档与代码同步压力小

## 4. 风险与回退

### 4.1 风险矩阵

| 风险 | 概率 | 影响 | 缓解 |
|------|------|------|------|
| Phase 间 cargo check 失败累积 | 中 | 高 | 每个 Phase 结束必须 0 errors |
| 跨任务测试互相干扰 | 中 | 中 | 用独立 `tests/integration_*.rs` 文件 |
| Provider trait 修改破坏老 Provider | 中 | 高 | `provider_id()` 加默认实现，不破坏 ABI |
| `DynProvider` 包装类型变化 | 低 | 高 | 已有测试覆盖 |
| Feature flag 破坏现有 build | 高 | 高 | `default = ["vector_db"]` 保证向后兼容 |

### 4.2 回退策略

如果某个 Phase 中间失败：
1. **立即停手**——不继续后续 Phase
2. **汇报失败的具体任务 ID** 和 `cargo check` 输出
3. **不 git revert**——保留失败现场以便诊断
4. **不修代码**——让用户决定修法

如果跨任务回归失败：
1. **二分定位**——注释掉最近一个 Phase 的所有改动，看哪个 Phase 引入
2. **汇报**——列出引入问题的具体任务
3. **不扩散**——不修其他任务以"绕开"问题

## 7. 阻塞汇报清单（汇总）

3 个计划共 **7 个"立即停手"阻塞项**：

1. **Skills B-7**：`ServicePlugin::shutdown` 签名不接收 `ap`，无法反注册 Provider
2. **Skills C-1**：`SkillInjectionProvider` 在 Assembler 侧引用违反"Slot 不依赖 Service 内部"原则
3. **MCP B-3**：timeout 配置字段在 `McpServerConfig` 还是 `McpConfig`？影响 connector API
4. **MCP B-5**：McpBundle 简化 vs 复杂方案
5. **MCP B-8**：`infra/metadata/` 目录约定是否存在
6. **MCP C-2**：MCP/Tools 启动顺序
7. **L3 A-2**：feature flag 改动是否会破坏其他模块对 `l3_vector` 的引用

每个阻塞项**遇到时立即停手汇报**，不绕过。
